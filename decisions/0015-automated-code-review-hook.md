# 0015 — Automated code review on every source change (hook + project subagent)
**Status:** Accepted · **Date:** 2026-10-28

## Context
The user wants every file change reviewed by a sub-agent that lives in this repo's `.claude/` folder.
Claude Code hooks run shell commands; they cannot start a subagent directly. A `type: "agent"` hook exists
but runs a generic verifier and cannot use a custom agent definition.

## Decision
- `.claude/agents/code-reviewer.md` — read-only reviewer (tools: Read, Grep, Glob, Bash; never edits).
  Reviews against CLAUDE.md + ADRs, traces callers, runs tests when cheap, verifies each finding has a
  concrete failure scenario, and reports severity-ranked findings with a verdict.
- `.claude/settings.json` — `PostToolUse` hook on `Write|Edit|MultiEdit|NotebookEdit` runs
  `.claude/hooks/review_on_change.py`, which returns `decision: "block"` + reason. On PostToolUse this does
  not undo the edit; it feeds an instruction back to Claude to delegate the review to `code-reviewer`.
- Guards in the script: only source/config files inside the repo; never `.env*`/keys (secrets must not be
  sent for review); skips docs, lockfiles, build output, autogenerated migrations; skips unchanged content
  (sha256); max 3 reviews per file per session to prevent fix→review loops; fails open on any error.

## Consequences
- Active only in Claude Code sessions started from `DetectionSystem/` (project-scoped settings).
- Each reviewed change costs one subagent run; related multi-file edits are batched into one review.
- Tune `MAX_REVIEWS_PER_FILE` / file filters in the script; disable via `/hooks` or by removing the entry.
